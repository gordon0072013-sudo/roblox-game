# Income plan — the realistic math + how to actually hit ~€20/day

No hype. Here's how the money works and what it honestly takes.

## How Robux becomes Euros
- Players spend Robux on your passes/products.
- Roblox takes a marketplace cut; you keep roughly **70%** of pass/product Robux.
- You convert Robux → cash via **DevEx** at roughly **$0.0035–$0.0038 per Robux**
  (≈ **€0.0032–€0.0035** depending on the rate). Rule of thumb:
  **~300 Robux ≈ €1** after the DevEx conversion.

## So what does €20/day require?
€20/day ≈ **~6,000 Robux/day** of *your* net earnings.

A common benchmark for a simple but decent clicker is **€0.005–€0.02 of revenue
per daily active player** (varies a lot by how fun/sticky it is). Using a
middle estimate of ~€0.01/player/day:

| Daily active players | Rough €/day |
|----------------------|-------------|
| 100                  | ~€1         |
| 500                  | ~€5         |
| 2,000                | ~€20        |
| 10,000               | ~€100       |

**Conclusion:** the code earns money per player automatically. Reaching ~€20/day
means getting on the order of **~1,000–2,000 daily players**. That's very
achievable on Roblox for a polished game, but it requires promotion — it will
not happen by itself.

## The promotion checklist (the part that isn't automatic)
1. **Good thumbnail + icon.** This is the single biggest driver of clicks on
   Roblox. Spend real effort here.
2. **Strong game name** with searched keywords (e.g. "Clicker", "Simulator").
3. **Tune retention**: rewards every few seconds, frequent "almost there"
   upgrade prompts. (The config already supports multipliers + auto-clicker.)
4. **Sponsored ads**: Roblox lets you pay Robux to get impressions. Start tiny,
   measure revenue-per-visit, scale only what's profitable.
5. **Social posts**: short gameplay clips on TikTok/YouTube Shorts tagged
   #Roblox. This is free and is how most small games break out.
6. **Update regularly**: new passes/areas keep players returning and spending.

## Levers you can pull in code (already built)
- Add more Game Passes / Developer Products in `Config.lua` (more to sell).
- Adjust prices and coin amounts to find the best price points.
- Increase `AutoClickerInterval` reward or add new multiplier passes.

## Honest bottom line
This repo is a finished, monetizable game — a real asset, not a toy. The path to
~€20/day is: **publish (15 min) → promote (ongoing) → tune what sells.** The
earning is passive; the *audience-building* is the work, and that part no tool
can fully do for you.
